# ToolBox

一个自托管的工具箱。编码工具、SSH 终端、文件传输、系统监控，都在一个界面里。

单用户，数据在自己机器上——本地 SQLite，或者你自己的服务器。没有账号体系，没有云端依赖，没有遥测。

网页端与 Windows 桌面端共用一套代码，桌面端把整个程序连同数据装进一个文件夹，拷走即迁移。

## 它能做什么

**编码**：JSON 格式化、Base64、URL 编解码、时间戳、哈希、UUID

**远程**：SSH 终端（多会话、主机指纹校验）、SFTP 文件管理（上传下载、改权限、递归删除）、系统监控（CPU / 内存 / 磁盘 / 网络 / GPU / NPU）

## 开始使用

需要 Node.js 22.12+ 与 pnpm 11+。

```bash
pnpm install
pnpm dev
```

打开 http://127.0.0.1:5173 ，首次进入会要求注册——用户名和密码都由你定，之后这个入口就关闭了。

桌面端另需 Rust stable 与 MSVC 工具链：

```bash
pnpm desktop:dev     # 开发
pnpm desktop:build   # 打包成安装程序
```

## 放在哪里

### 自己的服务器

```bash
cd docker
docker compose up -d --build
```

默认只监听 `127.0.0.1:7788`。需要局域网访问就把 `compose.yml` 里的端口映射改成 `"7788:7788"`。

域名、HTTPS、证书都交给反向代理，程序本身不关心这些。

### 带在身边

桌面版的所有数据都在程序旁边的 `data/` 目录里：数据库、窗口大小、日志。备份就是复制这个文件夹，迁移就是拷到新机器。

换图标、改端口、调会话时长——`.env.example` 里都有说明。

## 升级

覆盖安装到同一目录即可，`data/` 原地保留。

数据库结构变化时会在升级前自动备份一份，放在同目录，文件名形如 `local.db.v2-2026-11-02T11-30-00.bak`。备份永久保留，不会自动删。

想手动备份、下载或回滚，去「设置 → 数据」。恢复需要输入 `RESTORE` 确认——期间新增的数据会消失。恢复前还会自动存一份当前状态，选错了也还有退路。

2.0.0 不能从 1.x 升级，两者数据结构完全不同。具体每个版本能不能升，见 [CHANGELOG](CHANGELOG.md)。

## 一些边界

**单用户是刻意的。** 没有角色、没有权限组、没有审批流。你要的就是一个只有自己用的工具。

**本地与云端互不相干。** 两个数据源各自独立，切换只是换个连接，不会合并也不会覆盖。

**忘记密码只能重来。** 清掉 `users` 和 `sessions` 两张表，其它数据都还在。

**只打包 Windows。** 网页端跨平台，桌面端目前只出 Windows 版。

## 关于安全

密码用 Argon2id 存储。会话令牌 32 字节随机，库里只存摘要。SSH 凭据用 AES-256-GCM 加密落盘，密钥来自环境变量或自动生成的本地密钥文件。

桌面端 CSP 禁止渲染层直连外网，云端请求统一经 Rust 转发。本地 API 只接受来自 Tauri WebView 的跨源请求。

**一个诚实的前提**：本地加密能挡住「拿到数据库文件」的人。如果攻击者已经能以你的身份运行程序，任何本地加密都挡不住——那时候密钥就在他手边。
