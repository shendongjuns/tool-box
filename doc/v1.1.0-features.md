# ToolBox v1.1.0 版本说明

> 发布日期：2026-07-24  
> 模块：`tools/tool-database`（20 个源文件）

---

## 一、版本概述

v1.1.0 是 ToolBox **第一个功能性版本**，提供 5 个实用工具 + 全局基础设施，定位为 DBA/运维人员的日常工具箱。

v1.1.0 聚焦 **DBA 日常运维工具**的开发，后续版本将继续扩展开发辅助、文本工具、编解码等其他工具模块。

---

## 二、新增工具（侧边栏「数据库管理」分类）

### 2.1 数据库发现扫描器

**功能**：输入 IP → 扫描 9 种数据库端口 → 识别类型和版本号。

扫描范围：MySQL(3306)、PostgreSQL(5432)、ClickHouse(8123/9000)、Redis(6379)、MongoDB(27017)、SQL Server(1433)、Oracle(1521)、Elasticsearch(9200)

| 特性 | 说明 |
|------|------|
| TCP 端口扫描 | Java Socket 异步并发 |
| 服务识别 | 协议探测（MySQL 握手包、Redis PING/INFO、ES HTTP、CK HTTP ping） |
| 超时控制 | 默认 1000ms，可自定义 |
| 结果展示 | 端口/类型/版本/状态/延迟 表格 |

### 2.2 MySQL 备份

**功能**：MySQL 数据库整体/库/表的备份与 SQL 文件恢复。

| 特性 | 说明 |
|------|------|
| 连接管理 | 增删改查，JSON 持久化（安装目录/data/） |
| 整体备份 | 全部数据库导出为独立 .sql 文件 |
| 指定库备份 | 单个库完整导出（表+视图+函数+存储过程） |
| 指定表备份 | 选择库中的表，仅导出表结构+数据 |
| 分批导出 | 5000 行/批，流式写入文件，避免 OOM |
| 恢复导入 | 选择 .sql 文件执行恢复 |
| 停止备份 | 运行中可取消 |
| 错误提示 | 连接失败、导出失败等中文提示 |

**技术栈**：JDBC `mysql-connector-j:9.1.0` + HikariCP 连接池

### 2.3 ClickHouse 备份

**功能**：ClickHouse 数据库整体/库的备份与 SQL 文件恢复。

| 特性 | 说明 |
|------|------|
| 连接管理 | 增删改查，JSON 持久化（与 MySQL 共享存储） |
| 整体备份 | 全部数据库导出 |
| 指定库备份 | 单个库完整导出 |
| 分批导出 | 10000 行/批 |
| 恢复导入 | 选择 .sql 文件执行 |

**技术栈**：ClickHouse HTTP 接口（8123 端口）+ `HttpURLConnection`

## 三、新增工具（侧边栏「其他工具」分类）

### 3.1 任务列表

**功能**：跨工具的后台任务管理中心。

| 特性 | 说明 |
|------|------|
| 任务追踪 | 备份/导入等任务实时状态 |
| 进度显示 | 百分比进度条（如 75%） |
| 任务分类 | 按工具分组展示（MySQL/CK 等） |
| 状态标记 | 运行中/已完成/失败/已取消 |
| 清除管理 | 清除已完成任务 |

### 3.2 操作日志

**功能**：记录所有工具的操作历史。

| 特性 | 说明 |
|------|------|
| 全工具覆盖 | 发现扫描/MySQL/CK/设置/任务 |
| 事件记录 | 时间戳 + 工具名 + 操作 + 详情 |
| 级别区分 | INFO / SUCCESS / ERROR 图标标记 |
| 容量控制 | 最多保留 500 条，支持清空 |

### 3.3 系统设置

**功能**：配置全局存储目录。

| 特性 | 说明 |
|------|------|
| 存储目录 | 默认 `安装目录/data/`，可自定义 |
| 快捷选择 | 默认/文档/D盘 快速路径 |
| 磁盘信息 | 显示当前目录剩余空间 |
