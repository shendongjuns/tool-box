ToolBox 1.5.0 → 2.0.0 功能对比

一次彻底的重写：从 Windows 单机 Flutter 应用，变成「网页端 + 桌面端」的双形态、 可自托管的服务化产品。

整理时间：2026-10-22 · 对比基准：tag v1.5.0 与当前 main

一句话总结：1.5.0 是「一台电脑上的工具集」，2.0.0 是「自己的工具平台」。 前者功能多而深（SSH / SFTP / 仓库 / 监控），后者基础能力与体验强（账号、云端、双端、设计系统）， 但专业工具尚未迁移。两者不是升级，而是重写，无数据迁移。

9 · 结论

看什么结论
功能数量1.5.0 更多：4 个重型专业工具 + 备份体系
架构能力2.0.0 更强：多端、账号、云端、可部署
使用门槛1.5.0 更低：打开即用；2.0.0 需部署服务端（若用云端）
可维护性2.0.0 更好：TypeScript 全栈、共享契约、类型安全
数据安全2.0.0 更好：Argon2id、令牌哈希、CSRF、限流
迁移成本无迁移路径：1.x 数据不能导入 2.0
建议：如果日常依赖 SSH / SFTP / 仓库管理，继续用 1.5.0； 如果需要多设备、远程访问、或想要一个可持续扩展的平台底座，迁到 2.0.0 并把上述工具列入 Roadmap。 两者的数据与配置互不相通，可以并行安装。
