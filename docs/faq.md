# 常见问题

## 账号

### 忘记密码了

单用户系统没有找回的路——这是刻意的设计。

停掉服务，清空 `users` 和 `sessions` 两张表，重新打开就能重新建号。其它数据都还在。

```bash
# 桌面端
sqlite3 data/local.db "DELETE FROM sessions; DELETE FROM users;"

# Docker
docker compose exec toolbox \
  node -e "const db=require('better-sqlite3')('/app/data/toolbox.db');db.exec('DELETE FROM sessions; DELETE FROM users;')"
```

### 能开第二个账号吗

不能。这是刻意的。

### 密码有什么要求

只有一个：不能为空。长度、字符集都不限，中文、符号、空格都可以。

用户名 1-32 字符，同样不限制字符集。

## 数据

### 本地和云端的数据会同步吗

不会。它们各自独立，切换只是换个连接，不存在合并或覆盖。

桌面端可以在「设置 → 通用 → 数据源」里配置多个云端地址，每个都有自己独立的登录状态。

### 数据存在哪

| 平台        | 位置                                    |
| ----------- | --------------------------------------- |
| 桌面端      | `<程序目录>/data/local.db`              |
| 网页/Docker | `data/toolbox.db`（或 `DATABASE_PATH`） |

桌面端任何东西都不写到 AppData，删掉程序目录就是彻底卸载。

### 怎么迁移到另一台机器

复制整个 `data/` 目录即可。数据库、主机指纹、窗口状态都在里面。

别忘了 `.credential-key`——SSH 凭据的解密密钥在那里（如果你没自设 `CREDENTIAL_KEY`）。

## 远程管理

### SSH 连接提示主机指纹变了

这是一个**安全警告**，不是 bug。

第一次连接某台服务器时程序记住它的指纹。如果之后指纹变了，可能是：

- 服务器重装了系统
- 换了 SSH 密钥
- 有人在做中间人攻击

确认前两个原因之后，在弹窗里选择信任新指纹。拿不准就别连。

### SFTP 下载很慢

先确认瓶颈在哪。SFTP 的读取是串行请求-响应，吞吐上限是：

```
块大小 / RTT
1MB / 20ms = 50 MB/s
```

程序会根据实测延迟自动选择并行度（2 或 4 路）。如果还是慢，通常是：

- 服务器磁盘 IO 慢
- 网络本身带宽不足
- SSH 加密算法开销（部分老 CPU）

可以拿 `scp` 对比测试，如果 scp 也慢，就不是程序的问题。

### 删除文件夹会连带内容吗

会。递归删除，且需要二次确认。

SFTP 没有回收站，删了就是删了。

## 系统

### Windows 11 任务栏里找不到图标

系统默认把新图标折叠起来。点右下角的 `^`，或者到「设置 → 个性化 → 任务栏 → 其他系统托盘图标」里打开。

### 关闭窗口后程序还在

设计如此。关闭窗口是隐藏到托盘，不是退出。要真正退出，右键托盘图标选「退出」。

### 端口 7788 被占用

换一个：

```bash
PORT=8899 pnpm dev
```

这个变量前端代理也读，不用改两处。

### 打包桌面端时报「拒绝访问」

程序正在运行，先退出再打包。

### 支持 macOS 或 Linux 桌面端吗

目前只打包 Windows。代码本身跨平台（Tauri 支持），但没有测试过，也没做打包配置。

网页端在任何现代浏览器里都能用。

## 开发

### 加一个工具要改哪些地方

1. 在 `packages/contracts/src/tool-catalog.ts` 登记 id、名称、分组
2. 在 `apps/web/src/features/tools/` 写组件
3. 在 `apps/web/src/components/tools/tool-runner.tsx` 的 registry 里挂上

侧栏和命令面板会自动出现这个工具。
